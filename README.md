## 🚀 Featured Projects

### 📱 WhatsApp Bot V2
Modular WhatsApp bot with admin dashboard, MongoDB integration, role-based permission system, and one-command deployment. Handles 10K+ daily messages with real-time command routing.

### 🔍 Truecaller Clone
Phone number lookup app with reverse search, spam detection, and crowd-sourced database. Built with Express API and React frontend.

### 🎵 MP3 Music API
Music streaming API integrating YouTube Music and SoundCloud. Provides direct audio streams, metadata, and search with rate limiting and caching.

### 💬 Multi-Platform Streaming Engine
Unified messaging engine powering Telegram, Discord, and Messenger bots simultaneously. Supports media streaming, webhooks, and cross-platform synchronization.

### 🔐 WireGuard Chrome Extension
Browser extension for managing WireGuard VPN tunnels. One-click connect/disconnect, status monitoring, and config management directly from Chrome.
